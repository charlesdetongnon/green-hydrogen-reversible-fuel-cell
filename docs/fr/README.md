# Documentation en français

Ces documents sont des supports d'apprentissage. La solution officielle du concours est en anglais : voir le [README](../../README.md) et le [rapport technique](../report.md).

| Document | Contenu |
|---|---|
| [Partie 1 — Fondements](guide_1_fondements.md) | Le problème, les ressources, la physique expliquée équation par équation avec des exemples chiffrés, les choix de méthode |
| [Partie 2 — Construction](guide_2_construction.md) | Le code MATLAB et Simulink fichier par fichier, les simulations, les difficultés rencontrées |
| [Partie 3 — Résultats](guide_3_resultats.md) | Comment lire chaque figure, la validation, les limites, la conclusion |
| [Préparation à la défense](defense.md) | Présentation en deux minutes, chiffres clés, questions probables et réponses, démonstrations mathématiques, critiques, exercices |
| [Vidéo et soumission](soumission.md) | Exigences du concours, plan de la vidéo, liste de contrôle avant soumission |

Ordre de lecture conseillé : partie 1 en entier, puis partie 2 avec les fichiers ouverts à côté dans MATLAB, puis partie 3 avec les figures, et enfin la préparation à la défense.
